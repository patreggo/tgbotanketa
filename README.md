# Бот-анкетатор для закрытой Telegram-группы

Бот собирает имя и фамилию до подачи заявки в группу, показывает заявку администраторам с кнопками одобрения и ведёт реестр статусов.

## Что умеет

- принимает имя и фамилию, независимо от имени Telegram-аккаунта;
- связывает анкету с постоянным Telegram ID;
- создаёт персональную ссылку с заявкой на вступление;
- отправляет администраторам карточку заявки и кнопки «Одобрить» / «Отклонить»;
- отслеживает вступление и выход из группы;
- отдаёт администраторам сводку (`/status`), список (`/applications`) и CSV (`/export`).

## Подготовка группы

1. Создайте **закрытую супергруппу** Telegram.
2. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
3. Добавьте бота в группу администратором. Дайте ему право **приглашать пользователей** (Invite Users / Manage Invite Links). Для отслеживания входов и выходов также включите у бота право видеть изменения участников, если Telegram показывает эту настройку.
4. Узнайте числовой ID группы: временно добавьте в неё бота [@RawDataBot](https://t.me/RawDataBot), перешлите ему любое сообщение из группы и возьмите `chat.id`. Для супергруппы он начинается с `-100`.
5. Каждый администратор должен один раз написать вашему боту `/start`, иначе Telegram не позволит боту прислать ему заявку в личные сообщения.

## Установка и запуск (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и заполните `BOT_TOKEN`, `TARGET_CHAT_ID` и `ADMIN_IDS`. Затем запустите:

```powershell
python bot.py
```

Для постоянной работы бот нужно держать на включённом компьютере или сервере. В текущей версии используется long polling: отдельный веб-сервер не нужен.

## Как пользоваться

Разошлите людям ссылку вида `https://t.me/<имя_вашего_бота>?start=group`.

Пользователь заполняет анкету, нажимает «Подать заявку в группу» и отправляет заявку в Telegram. Бот присылает администраторам ФИО и Telegram ID. После нажатия «Одобрить» Telegram добавляет человека в группу.

Не раздавайте прямую ссылку на группу. Если кто-то всё же подаст заявку без анкеты, бот автоматически её отклонит.

## Безопасность данных

База хранится локально в `data/applicants.sqlite3` и исключена из Git. Ограничьте доступ к компьютеру/серверу, где работает бот, и сообщите участникам, что их ФИО сохраняются для допуска в группу.
